# Number theory for cryptography

This chapter introduces modular arithmetic, finite rings, prime fields, quadratic residues, and the number-theoretic tools used in later cryptographic constructions.

## Learning goals

By the end of this section, readers should be able to:

- Identify the central mathematical objects used in this part of the Chia protocol.
- Explain how the definitions in this chapter support later cryptographic constructions.
- Work through the examples and exercises that will be added as the textbook develops.
